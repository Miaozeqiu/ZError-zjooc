# 在浙学

本站是 zjooc.cn，智慧树是 zhihuishu.com。操作前确认实际域名与用户指定的课程、章节，不沿用其他平台的页面结构。

## 账号与入口

- 通过页面上的课程入口进入课程。目录、播放与作业的路径只作线索。
- 用户需要登录时调用 `browser_login_zjooc()`。已登录时可直接继续。缺少凭据时，支持安全填写的桌面端会在当前聊天显示账号密码表单；等待用户点击「保存并继续」，同一次调用会继续填写。账号密码只在该表单输入，经验和图谱只记录操作步骤。
- 用户取消填写时停止登录。若收到 `challenge: image_captcha`，请用户在在浙学网页输入图形验证码并点击登录，随后调用 `browser_login_zjooc()` 核对 `loggedIn: true`。收到手动登录提示时按回执处理。

## 章节与播放

- 目录常见于 `/plan` 或课程学习页左侧树。选择带播放图标的叶子节名；父节点可能只是章名，点击后须核对是否进入目标节。
- `/plan/detail` 一类播放页可能在顶部有多个视频页签。切换指定任务点后重新读取快照，定位播放器所在框；左侧通常仍是整门课程的目录，不用回目录来切换同节视频。
- 在目标小节的播放页调用 `browser_play_zjooc()` 启动当前视频。按名称播放时传 `title`，使用页签全名。收到 `watching: true` 后使用现有监控等待结束。
- 用户要求连续播放本小节时调用 `browser_play_zjooc({mode:"section"})`。宿主按页签顺序播放未完成的视频，等待每条视频自然结束。返回的 `ended` 是本次播到末尾的视频，任务点完成情况以网站标记为准。跨小节时按用户范围进入下一节，再调用工具。
- 正常加载或播放期间不反复刷新。明确加载失败且已停止加载时可刷新一次；刷新后重新定位原任务点，仍失败则说明阻塞。

## 自动作答

进入用户指定的作答页后调用 `browser_answer_zjooc()`。需要题库账号时，宿主会弹出 ZError 登录窗口，登录成功后继续当前批次。网站账号仍用于进入课程。

每批最多处理五题。收到 `nextOffset` 时，带上同一回执的 `assignment_id` 和新的 `offset` 继续。单题模式按用户指定范围通过网页的「下一题」切题。已有作答会保留，遇到 `needs_review` 或 `unverified` 要核对页面。

讲评页显示的正确答案会自动收集，完整试卷按需上传。作答时优先使用已公布答案，逐题回退到服务器题库、本地题库和模型。回执中的 `source` 可以区分答案来源，`filled` 表示网页已回读到所填内容。

## 作业与题序

- 作答路径常见 `/ucenter/student/course/study/.../homework/do/...`，按实际页面读取完整题干、题型和选项。
- 每题按独立 DOM 容器提取；按页面顺序返回数组，绑定「题型 + 显示题号 + 题干 + 容器 ID/ref + 选项」。单选、多选分组可能各自从 1 编号，不按数字 ID 排题，也不按换行拆选项。
- input 的 name 可能为空；选项需关联所在题目及其 label、value、checked。不能依靠字数阈值或标点向上寻找祖先，否则容易把包住多题的外层容器当作一题。
- 核对每个选项只属于一道题，题目数、题型和选项数与页面一致。点击后按显示题号逐题核对已选答案；勾选验证只证明控件状态，不证明保存、提交或答案正确。
- 读不清图片题时用视觉能力核对，文本模型无法辨认时报告阻塞，不猜测或把跳过算作完成。

## 范围与收尾

- 用户要求完成章节时默认包括范围内的视频和测验；明确只看视频、不答题或只暂存时遵守限制。
- 保存或提交后核对真实回执；已提交、待批阅或已完成的内容不擅自重做。
- 用实际页面状态核对用户指定范围，再 `browser_finish`。只读核对不推进课程；等待视频不等于任务完成，不能只说“稍后继续”就结束。
- 更新经验前先读取原文，保留已有内容并合并验证过的新方法。按工具返回的版本号保存到本地分支，不记录本次答案、临时 ref 或个人学习记录。
