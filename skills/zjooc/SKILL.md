# 在浙学

本站是 zjooc.cn，智慧树是 zhihuishu.com。操作前确认实际域名与用户指定的课程、章节，不沿用其他平台的页面结构。

## 账号与入口

- 使用宿主的凭据变量填写账号密码。用户提供明文时先保护凭据，不把账号、密码、Cookie 或验证码写入经验、图谱或脚本。
- 通过当前页面的真实课程入口进入；目录、播放与作业的路径只作线索，不拼接课程或作业标识猜入口。
- 验证码交用户处理；用户接管或停止后结束当前执行，不自动夺回控制权。

## 章节与播放

- 目录常见于 `/plan` 或课程学习页左侧树。选择带播放图标的叶子节名；父节点可能只是章名，点击后须核对是否进入目标节。
- `/plan/detail` 一类播放页可能在顶部有多个视频页签。切换指定任务点后重新读取快照，定位播放器所在框；左侧通常仍是整门课程的目录，不用回目录来切换同节视频。
- 用最新 ref、frameId/loaderId 操作真实播放控件。播放按钮没有文字时，可以点击该框内的原生 video；不得把另一条可见视频当作指定目标。
- 确认时间正常推进后建立 `browser_watch`，再用 `browser_wait` 等待事件。视频自然结束后重新读取页面，核对任务点状态，再做本节测验或下一节。不修改时间、倍速限制或伪造完成状态。
- 正常加载或播放期间不反复刷新。明确加载失败且已停止加载时可刷新一次；刷新后重新定位原任务点，仍失败则说明阻塞。

## 作业与题序

- 作答路径常见 `/ucenter/student/course/study/.../homework/do/...`，按实际页面读取完整题干、题型和选项。
- 每题按独立 DOM 容器提取；按页面顺序返回数组，绑定「题型 + 显示题号 + 题干 + 容器 ID/ref + 选项」。单选、多选分组可能各自从 1 编号，不按数字 ID 排题，也不按换行拆选项。
- input 的 name 可能为空；选项需关联所在题目及其 label、value、checked。不能依靠字数阈值或标点向上寻找祖先，否则容易把包住多题的外层容器当作一题。
- 核对每个选项只属于一道题，题目数、题型和选项数与页面一致。点击后按显示题号逐题核对已选答案；勾选验证只证明控件状态，不证明保存、提交或答案正确。
- 读不清图片题时用视觉能力核对，文本模型无法辨认时报告阻塞，不猜测或把跳过算作完成。

## 范围与收尾

- 用户要求完成章节时默认包括范围内的视频和测验；明确只看视频、不答题或只暂存时遵守限制。
- 保存或提交后核对真实回执；已提交、待批阅或已完成的内容不擅自重做。
- 用实际页面状态核对用户指定范围，再 `browser_finish`。只读核对不推进课程；等待视频不等于任务完成，不能只说“稍后继续”就结束。
- 更新经验前先读取原文，保留已有内容并合并验证过的新方法。按工具返回的版本号保存到本地分支，不记录本次答案、临时 ref 或个人学习记录。
