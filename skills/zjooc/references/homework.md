# 作业与章节测验

1. 用户要求作答时使用 `browser_site_zjooc__auto_answer`。每批默认四题、最多四题；后续批次保持 `assignment_id` 并传回执的 `next_offset`。题号范围使用 `question_range={start,end}`，重复或缺失的显示题号拒绝自动填写。
2. 答案依次来自页面官方解析、本机完整解析缓存、登录服务器题库、本地精确题库和模型。服务器使用现有 `/originalJson` 和 `/upload`；账号令牌由宿主注入，包只得到临时 `session_id`。首次无应用账号时弹出应用登录，真实认证失效时仅重新认证一次；取消登录、账号变化或 403 后停止填答。
3. 服务器答案按题型、完整题干和选项内容匹配，选项重排重新映射；同题重复、矛盾或截断数据不自动采用。本地题库多条命中须一致。模型只收到当前批次中尚无答案的题目，一次请求最多四题，不发送整份作业。
4. 只读用 `browser_site_zjooc__read_questions`，默认四题、最多八题。实填选项与普通填空值同步到软件题目面板。`question_id` 绑定文档、题序和题干选项指纹；填写前和填写后重新核对。单选、多选、判断使用当前选项字母 `choices`，填空用顺序一致的 `blanks`。
5. `browser_site_zjooc__answer_questions` 不覆盖不同的已有答案。`verified` 仅表示网页实填一致，不表示知识正确；不保存或交卷。含图、公式、混淆字体、材料题、过长内容和未知题型返回 `supported=false`，由 Agent 进一步核对。

`sync_review` 是运行包声明的页面自动任务：已登录应用时，打开解析页自动分批采集；离开、关闭、卸载或来源改变时撤销旧执行。后台不弹出登录、不产生模型请求、不点击网页。只在每道题都有可靠官方答案、总题数与实际题数一致且课程/试卷身份一致时上传完整副本，重试前先查询是否已有副本。不采集个人答案、姓名或分数。普通作答页不上传。

完整解析加密缓存按来源和应用账号隔离，七天过期，宿主统一限制总容量；卸载仓库会清理。跨批只保存解析数据和进度，不保存令牌、Cookie 或 DOM 引用。页面读取由通用固定 DOM 接口完成，不依赖旧版软件脚本，也没有注入网络拦截脚本。
