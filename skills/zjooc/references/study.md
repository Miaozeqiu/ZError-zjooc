# 章节工作流

使用 `browser_site_zjooc__study` 读取当前目录和页签后推进。`read_only=true` 不操作页面，`current_only=true` 不跨小节。每次只启动唯一可见的播放器，先应用静音再播放，使用媒体事件等待。再次自动暂停时停止争抢播放器，核对弹题、验证或用户暂停。

视频结束后重新检查平台完成图标，不能将 `ended` 当成章节完成。目录中下一节必须来自新读取的可见叶子条目；未知状态、未读取的目录分页不能报告完成。

`needs_quiz` 时读取本章测验，生成答案后逐题填答复核；需交卷时遵守用户授权。当前在浙学尚未核实讨论页面规则，因此不发布专用讨论工具。遇到 `needs_discussion` 时依据真实页面和用户授权使用通用浏览器工具处理，不猜测或调用不存在的仓库工具。

PDF/PPT/图书阅读在工作流中识别可见阅读器，按实际下一页、页码选择或滚动控件推进，尊重页面停留要求。也可用 `browser_site_zjooc__read_document` 检查当前阅读器。阅读位置不推进时停止。翻页和滚动不代表平台学分登记，不直接调用伪造完成接口。

中断时保存语义检查点，不保存密码或过期选择器。`workflowPending=true` 可恢复等待；恢复先重新观察页面，遇到讨论发布不确定时禁止自动重发。
